# Print IMS (印刷行业综合管理系统)

## Tech Stack
- Backend: Java 17, Spring Boot 3.2.5, MyBatis-Plus 3.5.5
- Frontend: Vue 3, TypeScript, Vite, Element Plus

## Project Structure
- `backend/src/main/java/com/printims/` — Java backend
- `frontend/src/` — Vue 3 frontend
- `sql/` — Database scripts

## Code Standards
- Backend: Spring Boot conventions, Lombok, MyBatis-Plus
- Frontend: Vue 3 Composition API, TypeScript, Element Plus UI
- Chinese comments acceptable
